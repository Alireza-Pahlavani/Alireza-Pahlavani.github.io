P1KOOPMAN / EDMD

Held-out nonlinear prediction

A reproducible Duffing-like benchmark with trajectory-level train, validation, and test separation, ridge-selected EDMD, and a linear DMD reference model.

84.6%lower multistep RMSE vs. linear DMD

Python · NumPy · SciPy · automated tests

Synthetic benchmark; result is scenario-specific, not a claim of general performance.

P2SAFE MULTI-AGENT CONTROL

Safety and connectivity under motion

Four-agent coordination with pairwise separation, bounded communication edges, a moving obstacle, and a constrained safety filter applied to nominal goal-seeking commands.

100%solver success in the recorded demonstration

Python · constrained optimization · simulation

Deterministic portfolio demonstration with single-integrator dynamics.

P3EV / V2G OPTIMIZATION

Departure-aware charging

A 24-hour linear-programming example that respects battery and charger constraints, reaches the required departure state of charge, and compares against immediate charging.

Python · linear programming · CSV reporting
